# QABAT — портфолио

HTML / CSS / Vanilla JavaScript. Құрастыру кезеңі және сыртқы runtime кітапханалары жоқ. `dist/index.html` файлын ашуға немесе `dist/` мазмұнын статикалық хостингке орналастыруға болады.

## Екінші нұсқа

Сайт толығымен қайта құрылды: ірі типографика, нақты WebGL Q мүсіні, толық экрандық бөлім ауысуы, скроллда қабатталатын жоба беттері, ашылатын кейстер, тақырыптың дөңгелек ауысуы және мобильді мәзір. Мәтіндер қазақша, орысша және ағылшынша жазылған.

## Құрылым

1. Hero — сайт әзірлеуші туралы қысқа таныстыру, 3D Q, жобаға өту.
2. Жобалар — SÄULE, TOLQYN, AURA; сүзгі және жеке жоба терезелері.
3. Мен туралы — жұмыс бағыты, технологиялар, қызметтер.
4. Жұмыс барысы — танысу, дизайн, әзірлеу, іске қосу.
5. Байланыс — телефон, WhatsApp және форма.
6. Footer — бренд, жыл, жоғарыға өту.

Жобалар — авторлық дизайн концепттері. Нақты клиенттік тапсырыс, жұмыс тәжірибесі немесе нәтижелер ойдан қосылмаған. Өз жұмыстарыңызды енгізу үшін карточкаларды, SVG/суреттерді, `PROJECTS` объектісін және үш тілдегі сипаттамаларды жаңартыңыз.

## 3D және қозғалыс

Нысан CSS сақиналары емес: `scene.js` WebGL 1 арқылы үшбұрыштарды тереңдік буферімен салады. Металл материалдың шағылысуы GLSL шейдерінде есептеледі. Объектіні тінтуірмен, саусақпен немесе бағдарша пернелерімен бұруға болады; Home бастапқы қалыпқа қайтарады.

Десктопта геометрия: 9 474 төбе / 18 216 үшбұрыш. Мобильдіде: 4 102 / 7 728. Рендер шегі 30/24 кадр/с, pixel ratio шегі 1.6/1.25. Бұлар — кодтағы шектеулер; нақты құрылғыдағы өлшенген FPS емес. Көрінбегенде, басқа бетке өткенде, мәзір/жоба терезесі ашылғанда GPU циклі тоқтайды. `prefers-reduced-motion` және қозғалысты тоқтату батырмасы ескерілген.

WebGL істемесе немесе контекст жоғалса, сол шейдер мен геометриядан алынған статикалық WebP көрінеді. Бұл жағдайда сүйреу нұсқауы көрсетілмейді және көрінбейтін canvas фокус алмайды.

Бөлім ауысуы пайдаланушы навигацияны басқанда ғана жүреді. Кәдімгі скролл ұсталып қалмайды. Телефонда жоба беттері табиғи тізіммен ашылады; ноутбук пен кең экранда қабаттасу әсері қолданылады.

Форма есімді, телефон/email және жоба сипаттамасын тексеріп, WhatsApp-та дайын хабарлама ашады. Жіберуді пайдаланушы WhatsApp-та растайды. Серверде өтінім сақталмайды. Бұл код нөмірде WhatsApp тіркелгісінің бар-жоғын тексермейді.

Телефонды ауыстырғанда `PHONE`, `DISPLAY_PHONE`, HTML-дегі `tel:` / `wa.me` және көрсетілетін нөмірлерді бірге өзгертіңіз.

## Контентті өзгерту

`script.js` ішіндегі `COPY.kk`, `COPY.ru`, `COPY.en` — барлық сайт мәтіні. Жоба деректері `PROJECTS` ішінде, ал визуалдар `assets/` ішінде. Түстер `styles.css` басындағы CSS Variables арқылы өзгереді. Тіл, тақырып және қозғалыс таңдауы браузерде сақталады; localStorage бұғатталса да сайт жұмыс істейді.

## Нақты орындалған тексерістер

- JavaScript файлдарының синтаксисі.
- Үш тілдегі 118 бірдей кілт және HTML-де қолданылған аудармалар.
- DOM моделінде тіл/тақырып, 3/2/1 сүзгі, мәзір, пернетақта, фокус, кейс терезелері, бөлім ауысуы және қозғалыс күйі.
- Форманың жарамсыз деректері, email/телефон, Unicode мәтіні бар WhatsApp URL және нөмірді көшіру.
- WebGL шейдерлері нақты OpenGL ES контекстінде құрастырылып, байланыстырылып, 3D кадрлар салынды. Десктоп және мобильді mediump жолдары өтті.
- Геометрияның координаттары, нормальдары, үшбұрыш бағыттары және анимация кезіндегі кадр шекаралары.
- Дәл 3D нысанның жарық/қараңғы рендерлері және үш SVG концепті көзбен қаралды.
- Нақты қаріппен 320, 390, 768, 1024 және 1440px ендерде үш тілдегі тақырыптардың ені өлшенді; 45 тексеріс өтті. Й/Қ әріптеріне тік бағытта қосымша орын берілді.

Браузерді басқару құралы бұл ортада қолжетімсіз. Сондықтан сайттың толық браузерлік скриншоты, нақты телефондағы touch мінезі, View Transition көрінісі, Lighthouse және құрылғы FPS өлшенген жоқ. Жоғарыдағы тексерістер солардың орнына браузер тесті өтті дегенді білдірмейді.

## 3D ауысулар

- Бөлім ауысуы: төрт жолақ 3D бүктеліп жабылады, келесі бөлім сол арқылы ашылады.
- Жоба терезесі: карточка сияқты бұрылып ашылады. Жабылғанда да бұрылады (жабу батырмасы, Escape, сыртын басу). Суреті мен мәтіні бөлек кіреді.
- Мобильді мәзір: сілтемелер 3D бұрылып шығады.

Қозғалыс тоқтатылған немесе `prefers-reduced-motion` болса, барлық ауысу бірден өтеді.
